001 Public repo aws-incident-copilot

AWS Incident Co-Pilot

A command-line tool that watches AWS infrastructure, detects incidents, pulls evidence from CloudWatch and CloudTrail, and sends alerts. Built so engineers without a DevOps background can run it.

  • Detects EC2 CPU spikes, Lambda errors, Bedrock token overages, and S3 permission problems, with configurable thresholds.
  • Collects CloudWatch and CloudTrail evidence automatically for each incident.
  • Alerts over SNS and email. A mock mode lets you test safely before deploying.
  • Modular design covering EC2, Lambda, S3, SNS, Bedrock, and DynamoDB.

Python · AWS · CloudWatch · CloudTrail · pytest · CI/CD

002 Public repo k8s-cost-optimizer

Kubernetes Cost Optimizer

A multi-cloud cost platform for Kubernetes. It recommends changes aimed at cutting infrastructure spend by 35–45%.

  • Tracks cost in real time across AWS, GCP, and Azure, and compares prices between them.
  • ML-driven recommendations for right-sizing, spot instances, autoscaling, and node consolidation.
  • FastAPI backend, a Kubernetes Operator in Go, a React dashboard, and PostgreSQL and Redis underneath.
  • 90% test coverage across unit, integration, end-to-end, load, and chaos tests.

Python · Go · React · Kubernetes · PostgreSQL · Terraform
